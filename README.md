## 📌 About The Project

NOORÉ is a premium women's fashion boutique website concept created
to demonstrate how a small fashion business can present its brand,
collections and customer contact options online.

The website focuses on a clean, elegant and mobile-friendly user
experience.

---

## ✨ Features

- 🏠 Modern luxury-style homepage
- 👗 Fashion category showcase
- 🛍️ Featured product collection
- 🔎 Product category filtering
- 👀 Product quick-view popup
- 📱 Fully responsive design
- 📲 Mobile navigation menu
- 💬 WhatsApp enquiry button
- 📸 Instagram integration
- 📖 About the brand section
- 📍 Contact and business information
- ✨ Smooth scrolling and animations
